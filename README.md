# 박주임 캡처 · 0.4.0

Windows에서 영역·창을 캡처하고 설명을 붙이는 개인용 데스크톱 프로그램입니다. [oh-my-opensnap for Windows의 README](https://github.com/Canine89/oh-my-opensnap-win)에 공개된 기능 설명을 참고하여 독립적으로 구현했습니다. 원본 프로그램의 소스 코드·로고·브랜드를 가져오지 않았습니다.

이 프로그램은 IT 기획·편집자인 **편집자P**님의 [유튜브 영상](https://youtu.be/VrPCmJHmF6o?si=rWLCnvMw09evkwHY)에서 배포한 프로그램을 보고 AI를 통해 제작하였습니다.

0.2에서는 Apple 미리보기 앱을 참고한 밝은 화면, 둥근 버튼, 직접 그린 선 아이콘을 적용했습니다. 왼쪽에서 캡처·보관함을 관리하고, 위에서 편집 도구를 선택한 뒤 오른쪽 위의 **복사 / 이미지 저장**으로 마무리합니다. Apple의 전용 글꼴·아이콘은 사용하지 않았으며 Windows 창 조작은 유지합니다.

0.2.1에서는 여러 버튼의 글자 겹침을 방지하도록 배경을 완전히 다시 그리고, 실제 글자 크기와 DPI를 기준으로 아이콘·글자 영역을 따로 계산합니다. 글자 크기가 커져 도구가 한 줄에 들어가지 않으면 다음 줄로 배치합니다.

0.3에서는 이미지 프레임 크기 조절, 캐릭터 로고, 하단 블로그·이메일 링크, 알기 쉬운 숫자 단축키 표기, 영역 선택 후 이미지·영상 선택 팝업을 추가했습니다.

0.4에서는 GitHub Releases를 통한 새 버전 자동 확인과 앱 내 업데이트를 지원합니다. [최신 버전 다운로드](https://github.com/kijung4290/park-capture/releases/latest) · [소스 저장소](https://github.com/kijung4290/park-capture).

## 바로 실행하기

1. [최신 릴리스](https://github.com/kijung4290/park-capture/releases/latest)에서 **`ParkCapture-버전-portable.zip`**을 받아 쓰기 가능한 폴더에 전체 압축을 풉니다.
2. **`ParkCapture.exe`**를 실행합니다. 소스 폴더에서는 **`실행.cmd`** 또는 **`bin\ParkCapture.exe`**로 실행합니다.
3. **새 캡처** 또는 캡처 단축키 → 영역을 드래그하거나 창을 클릭 → 팝업에서 **이미지 캡처 / 영상 녹화**를 선택합니다.
4. 캡처는 자동 저장되고 클립보드에도 복사됩니다. 한글·Word·PowerPoint 등에 **Ctrl+V**로 붙여 넣을 수 있습니다.

처음에는 가운데 **새 캡처 / 이미지 가져오기** 버튼으로 시작하세요. 편집할 이미지가 없을 때는 편집 도구가 비활성화됩니다. 다시 실행하면 가장 최근 파일을 엽니다. 오른쪽 위 **···** 메뉴에서 단축키 안내와 파일 관리를 사용할 수 있습니다.

대상: Windows 10/11, .NET Framework 4.8. 별도 서버·로그인·API 키는 사용하지 않습니다. 관리자 권한 없이 실행합니다. `ParkCapture.exe.config`와 `ParkCapture.Updater.exe`를 실행 파일과 같은 폴더에 두세요.

닫기 버튼은 기본적으로 프로그램을 알림 영역에 숨깁니다. 완전히 끝내려면 시계 옆 캐릭터 아이콘을 우클릭한 뒤 **종료**를 선택합니다. 이 동작은 설정에서 바꿀 수 있습니다.

## 캡처

| 동작 | 조작 |
| --- | --- |
| 캡처 시작 | **Ctrl+Shift+2** — 설정에서 변경 가능 |
| 영역 선택 | 마우스로 드래그 |
| 창 선택 | 창 위에서 클릭 |
| 창 전체 / 본문 전환 | **Tab** — 창 본문은 Windows의 클라이언트 영역 기준 |
| 이미지 저장 | 영역 선택 후 팝업의 **이미지 캡처** 또는 **Enter** |
| 선택 영역 녹화 | 팝업의 **영상 녹화 / R**, 또는 왼쪽 화면 녹화 버튼 |
| 다시 선택 | 팝업의 **영역 다시 선택** |
| 영역 위치 미세 이동 | 팝업이 없는 영역 선택 화면에서 방향키 1px / Shift+방향키 10px |
| 취소 | **Esc** 또는 우클릭 |

화면을 정지한 뒤 선택합니다. 선택 영역 크기, 십자선, 픽셀 확대경, 화면 좌표, HEX 색상을 표시합니다. 여러 모니터를 포함한 가상 화면의 물리 픽셀 좌표를 사용합니다.

캡처 단축키를 누르면 **영역 선택 → 캡처 방식 팝업 → 선택한 작업 진행** 순서로 이어집니다. 이미지를 선택하면 자동 저장·클립보드 복사·편집기로 이어지고, 영상을 선택하면 같은 영역에서 녹화가 시작됩니다. 취소하면 파일을 만들지 않습니다.

설정의 **숫자 3 (위쪽)**은 F1~F12 줄 바로 아래 숫자 3 키입니다. 이전 표시인 `D3`와 같은 키이며 오른쪽 숫자판은 **키패드 3 (오른쪽)**으로 따로 선택합니다. 기존에 저장한 단축키는 그대로 유지됩니다. 오른쪽 키패드는 Num Lock을 켜서 사용하세요.

## 편집

왼쪽 보관함에서 이미지를 선택하고 위쪽 아이콘과 한글 이름이 있는 도구를 누릅니다. 도구 아래에 조작 방법과 해당 도구에 필요한 색상·굵기·글자 크기가 표시됩니다. 이미지 파일을 캔버스에 끌어 놓거나 **Ctrl+O**로 가져올 수도 있습니다. 외부에서 가져온 파일은 보관함에 복사하므로 외부 원본은 바뀌지 않습니다. **Ctrl+V**로 클립보드의 이미지를 가져올 수 있습니다.

| 도구 | 단축키 | 사용법 |
| --- | --- | --- |
| 선택 | V | 요소를 클릭해 선택 → 요소 삭제 또는 Delete. 드래그로 이동, 오른쪽 아래 손잡이로 도형 크기 조절 |
| 자르기 | C | 영역을 드래그 → Enter 또는 자르기 적용. 영역 선택 후 적용 버튼 활성화 |
| 크기 조절 | S | 이미지의 모서리·테두리 드래그, 또는 가로·세로 픽셀 입력 → 크기 적용 |
| 번호 | N | 클릭마다 1, 2, 3… |
| 글자 | T | 클릭 → 내용 입력 |
| 말풍선 | B | 드래그 → 내용 입력 |
| 화살표 | A | 드래그. Shift를 누르면 45도 단위로 고정 |
| 사각형 / 원 | R / O | 드래그. Shift를 누르면 정사각형 / 정원 |
| 가리기 | M | 가릴 영역을 드래그. 강도 값으로 모자이크 블록 크기 조절 |
| 가로 / 세로 띠 삭제 | 더 보기 메뉴 | 없앨 영역을 드래그 → Enter |

도구 단축키는 캔버스에 포커스가 있을 때 작동합니다. 선택한 주석의 색상·굵기·글자 크기를 바꿀 수 있고, 글자·말풍선은 선택 도구에서 더블클릭하여 내용을 수정할 수 있습니다.

### 이미지 프레임 크기 조절

1. **크기 조절** 도구를 누르거나 **선택** 도구에서 주석을 선택하지 않은 상태로 둡니다.
2. 이미지 둘레의 8개 손잡이 또는 테두리를 끌어 크기를 바꿉니다. 드래그 중 새 픽셀 크기를 미리 보여주고, 마우스를 놓으면 적용합니다. **Esc**는 적용 전에 취소합니다.
3. 크기 조절 도구의 **가로·세로** 칸에 픽셀을 입력하고 **크기 적용**을 눌러 정확한 크기로 바꿀 수도 있습니다.

기본으로 **비율 유지**가 켜져 있습니다. 이를 해제하거나 드래그 중 **Alt**를 누르면 가로·세로를 자유롭게 바꿉니다. 이미지를 자르는 기능과 달리 이미지 전체의 픽셀 수를 조절합니다. 주석의 위치·크기도 함께 조절하며 글자와 번호의 형태는 읽기 쉽게 유지합니다. **Ctrl+Z / Ctrl+Y**로 되돌리거나 다시 적용할 수 있습니다. 저장·복사에는 조절한 크기가 사용되고 캡처 원본은 보존됩니다. 최대 한 변 16,384px / 전체 6,400만 픽셀까지 지원합니다.

- **Ctrl+Z / Ctrl+Y**: 실행 취소 / 다시 실행. 크롭과 띠 삭제도 되돌릴 수 있습니다.
- **요소 삭제 / Delete / Backspace**: 선택한 번호·글자·말풍선·화살표·도형·모자이크를 하나씩 삭제. **선택(V)** 도구로 요소를 클릭하면 파란 테두리와 삭제 버튼이 활성화됩니다. 어떤 도구에서든 요소를 **우클릭 → 요소 삭제**로 지울 수도 있습니다. **Ctrl+Z**로 복구하고 **Esc**로 선택을 해제합니다. 선택만 할 때는 실행 취소 기록을 추가하지 않습니다.
- **방향키 / Shift+방향키**: 선택 주석을 1px / 10px 이동.
- **마우스 휠**: 확대·축소. 가운데 버튼 드래그: 화면 이동.
- **Ctrl+0** 또는 맞춤: 이미지 전체를 창에 맞춤.
- **Ctrl+C** 또는 복사: 주석을 합성하여 현재 편집 이미지의 픽셀 크기로 클립보드에 복사.
- **이미지 저장**: 주석을 합성한 PNG / JPG를 다른 파일로 저장. 96 DPI로 저장합니다.

편집은 마지막 변경 후 약 0.9초 뒤 자동 저장합니다. Ctrl+S로 즉시 저장할 수 있습니다. 실행 취소 기록은 현재 열린 이미지에서 최대 16단계 / 약 192 MiB까지 보관합니다. 프로그램을 다시 열면 주석 편집은 이어 할 수 있지만 실행 취소 기록은 초기화됩니다. 크롭과 띠 삭제를 적용하면 그 이전 주석은 편집용 이미지에 합성됩니다.

## 영상

이 PC에서는 설치되어 있는 FFmpeg를 자동으로 찾아 사용합니다. 다른 PC에서 영상 기능을 쓰려면 **FFmpeg의 `ffmpeg.exe`**를 준비해야 합니다.

- 설정 → FFmpeg 경로에서 설치된 실행 파일 지정.
- 또는 프로젝트의 **`tools\ffmpeg.exe`**에 배치.
- 또는 FFmpeg가 있는 폴더를 PATH에 등록.

FFmpeg가 없더라도 이미지 캡처·편집은 작동합니다. FFmpeg는 이 프로그램에 포함하거나 자동으로 다운로드하지 않습니다. [공식 FFmpeg 다운로드 안내](https://ffmpeg.org/download.html)를 참고하세요.

1. 캡처 단축키 → 영역 선택 → 팝업의 **영상 녹화**, 또는 왼쪽 **화면 녹화** → 영역 선택 → Enter.
2. 작은 녹화 창에서 **일시정지 / 다시 시작 / 녹화 마침**을 사용합니다.
3. 보관함에서 MP4를 선택하고 **영상 내보내기** 또는 가운데 **영상 재생 · 편집**을 누릅니다.
4. 기본 플레이어로 재생하여 시간을 확인합니다. 시작·끝을 초 단위로 지정하고 MP4 / GIF로 내보냅니다.

화면은 30fps MP4로 녹화합니다. 오디오는 녹음하지 않습니다. 내보내기는 0.5 / 1 / 1.5 / 2 / 4배속과 GIF 15 / 30 / 45fps를 지원합니다. 해상도를 줄이지 않으며, MP4는 코덱 제약 때문에 홀수 크기의 오른쪽 또는 아래쪽에 최대 1px을 덧붙입니다. 처리 중 취소하면 완성되지 않은 출력 파일을 제거합니다. 녹화 저장에 실패하면 안내된 임시 폴더의 구간 파일을 보관합니다.

## 파일 위치와 원본 보존

- 기본 캡처 폴더: **내 사진\박주임 캡처**. 설정에서 변경 가능.
- 원본: 캡처 폴더의 `Capture_날짜_시간_식별자.png` / `.mp4`.
- 편집 내용: 캡처 폴더의 **`.parkcapture\원본파일이름\`**.
- 설정·오류 로그·녹화 임시 파일: **`%LOCALAPPDATA%\ParkCapture`**.

이미지를 복사하거나 저장할 때 주석을 합성합니다. 원본 파일은 덮어쓰지 않습니다. **편집까지 백업하려면 `.parkcapture` 폴더도 함께 복사하세요.** 원본에는 모자이크 전 정보가 남으므로, 가린 이미지를 공유할 때는 **이미지 저장으로 만든 파일**을 사용하세요.

보관함은 오늘·어제·최근 7일·이전으로 묶으며 최근 500개까지 표시합니다. **전체 / 이미지 / 영상** 버튼으로 필터링하고, **캡처 검색**에서 파일명이나 날짜(예: `2026`, `10.15`)로 찾을 수 있습니다. 저장하면 미리보기에도 편집 결과가 반영됩니다. 이전 파일은 저장 폴더에서 열 수 있습니다. 목록 우클릭에서 복사·저장·파일 위치·휴지통 이동을 사용할 수 있습니다.

## 자동 업데이트

- 앱 시작 약 3초 뒤와 이후 **6시간마다** 공개 GitHub Releases의 정식 최신 버전을 확인합니다. 개발 중 소스나 미리보기 릴리스는 배포하지 않습니다.
- 새 버전 안내에서 **업데이트 후 재시작**을 누르면 다운로드 → 서명·SHA-256·파일 구성·실행 파일 버전 확인 → 편집 저장 → 파일 교체 → 앱 재실행 순서로 적용합니다. **나중에 / 취소**를 선택하면 현재 버전을 계속 사용합니다.
- 오른쪽 위 **··· → 업데이트 확인…** 또는 알림 영역 메뉴에서 직접 확인할 수 있습니다. **설정 → 새 버전 자동 확인**으로 자동 확인을 끌 수 있습니다.
- 캡처·녹화 중에는 업데이트 적용을 미룹니다. 창이 알림 영역에 숨겨져 있으면 돌아왔을 때 안내합니다. 파일 교체에 실패하면 교체한 앱 파일을 되돌립니다.
- 캡처 원본·편집 데이터·설정·FFmpeg는 교체하지 않습니다. 앱을 쓰기 권한이 없는 폴더에 두었으면 쓰기 가능한 폴더로 이동하세요.
- **0.3.1 이하 버전은 자동 업데이트가 없으므로 0.4 이상 ZIP을 한 번 직접 받아야 합니다.** 이후 버전부터 앱 안에서 업데이트할 수 있습니다.
- 확인 실패는 작업을 방해하는 팝업 없이 다음 확인 때 다시 시도합니다. 수동 확인에서는 원인을 안내합니다. GitHub에 연결할 수 없는 환경에서는 자동 업데이트를 사용할 수 없습니다.

업데이트 검증에는 앱에 내장한 RSA 공개 키를 사용합니다. 이것은 Windows Authenticode 코드 서명과 별개이며, 배포 실행 파일은 현재 Authenticode 서명되지 않았습니다. 업데이트 임시 파일·백업·오류 기록은 `%LOCALAPPDATA%\ParkCapture\Updates` 아래에 보관합니다.

## 원본 README와의 차이 / 현재 한계

- 이름·화면 구성·구현 방식이 다른 독립 프로그램입니다.
- 설치 프로그램 없이 포터블로 실행하며, GitHub를 통한 앱 내 업데이트를 지원합니다.
- 동영상은 기본 플레이어로 재생하고, 편집 창에서 시간을 입력합니다. 내장 플레이어·시각적 타임라인은 없습니다.
- 화면만 녹화합니다. 시스템 소리·마이크 녹음은 없습니다.
- 한국어 / English를 설정할 수 있습니다. 언어는 알림 영역 메뉴에서 완전히 종료한 뒤 다시 실행하면 적용됩니다.
- 다중 모니터·고배율을 위한 DPI 설정과 물리 좌표 처리를 구현했지만, 이번 환경에서는 서로 다른 배율의 복수 모니터와 ARM PC를 실기 검증하지 못했습니다.
- 게임의 독점 전체 화면, DRM 보호 영상, 보안 데스크톱 등은 캡처가 제한될 수 있습니다. 고해상도 30fps 녹화 성능은 PC 사양에 따라 달라집니다.

## 소스 수정과 빌드

별도 NuGet 패키지나 .NET SDK 없이 Windows의 .NET Framework C# 컴파일러를 사용합니다.

```powershell
# 프로젝트 폴더에서
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

# 핵심 동작·버튼 렌더링·업데이트 검증 후 빌드
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test

# 데모 이미지와 UI 검증, 화면 미리보기 저장 후 자동 종료
.\bin\ParkCapture.exe --preview "C:\Temp\parkcapture-preview.png"

# 배포용 ZIP 생성
# 서명용 개인 키가 있는 로컬 PC 또는 GitHub Actions에서 실행
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\release.ps1
```

### 이후 버전 배포하기

1. 코드를 수정하고 `src/AssemblyInfo.cs`의 `AssemblyVersion`, `AssemblyFileVersion`을 같은 새 버전으로 올립니다. 예: `0.4.1.0`.
2. `README.md`의 버전과 `RELEASE_NOTES.md`를 갱신하고 로컬에서 `build.ps1 -Test`를 실행합니다.
3. `main`에 커밋·푸시합니다. GitHub Actions가 Windows에서 검증·빌드하고 ZIP과 서명된 업데이트 명세를 만들어 새 버전 릴리스를 게시합니다.
4. 기존 사용자 앱이 다음 확인 때 새 버전을 안내합니다. 이미 게시된 버전은 다시 덮어쓰지 않으므로 수정 배포 시 버전을 올리세요.

서명 키는 저장소에 포함하지 않습니다. GitHub Actions의 **`PARKCAPTURE_SIGNING_KEY`** Secret에 저장했으며, 이 PC의 원본은 `%LOCALAPPDATA%\ParkCapture\release-signing-key.xml`에 현재 사용자만 접근할 수 있게 보관합니다. 키를 공개하거나 삭제하지 마세요. 빌드만 할 때는 공개 키만 있으면 됩니다. 포크에서 별도로 배포하려면 저장소 주소와 공개 키를 자신의 것으로 교체하고 서명용 Secret을 설정해야 합니다.

`--preview`는 임시 데모 폴더와 데모 이미지를 사용합니다. 검증 중 앱이 잠깐 화면에 표시되며, 앱 내부 이벤트를 통해 주석·크롭·캡처·짧은 화면 녹화까지 확인합니다. FFmpeg가 없으면 영상 관련 검증은 건너뜁니다. 배율이 혼합된 다중 모니터 등 미검증 항목은 위의 한계를 참고하세요.

`ParkCapture.exe --button-checks "출력폴더"`로 100 / 125 / 150 / 175 / 200% 글자 확대 조건의 버튼 미리보기와 검사 결과를 저장할 수 있습니다. 이는 현재 모니터에서 글꼴 크기를 바꾸는 렌더링 검사이며 Windows 디스플레이 배율 자체를 변경하는 검사는 아닙니다.
